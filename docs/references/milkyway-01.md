# 参考画像: 天の川銀河（実写）

## 画像の概要

天の川銀河の中心部を捉えた長時間露光写真。銀河中心（いて座方向）を含む、
実際の夜空の色と構造。

## 現在のfortunePとの差分

| 要素 | fortuneP現在 | 実際の夜空 |
|---|---|---|
| 背景ベース | 均一な深ネイビー `#060c1e` | 青灰 `#0d1528`、部分により変化 |
| 星雲グロウ | 青のみ（下部） | **ピンク/マゼンタの星雲**が点在 |
| 暖色 | ボケ玉（金）のみ | 銀河コアが**琥珀/クリーム**に発光 |
| 構造 | 均一・対称 | 対角線状の天の川帯 + ダスト |

## 色分析

```
銀河コア中心:    #d4b080 〜 #c09050  (暖色・明るい)
銀河帯:         #6a4830 〜 #3d2810  (暖色・暗い)
ダスト暗黒帯:    #0a0e18 〜 #12182a  (ほぼ黒)
ピンク星雲①:    rgba(200, 80, 180, 0.6)  (右上)
ピンク星雲②:    rgba(180, 60, 160, 0.4)  (左下)
背景星空:        #1a2540 〜 #0d1525  (青灰)
明るい星:        #ffffff + #b0d4ff   (白・青白)
```

## 構造パターン

```
右上 ─────── 青灰の星空 + 白い点星の密度
    \
     \  ← 天の川帯（対角線、暖色）
      \
       ▓  ← 銀河コア（琥珀の発光）
      /
     /  ← ダスト暗黒帯
    /
左下 ─────── ピンク星雲 + 散乱した白い星
```

## fortunePへの示唆

### 最重要: 暖色と冷色の共存

現在のfotunePは「冷色一辺倒」。実際の夜空には必ず暖色が存在する。

前画像（魔法の森）と合わせると：
- **小宇宙スケール**: 森の窓の光 → 温かみのある魔法陣 → ユーザーの手元
- **大宇宙スケール**: 銀河コアの琥珀 → 宇宙の暖かさ

どちらも「冷たい闇の中の暖かい光」というテーマを持つ。

### ピンク/マゼンタ星雲の追加

HII（エイチツー）領域（水素ガスが恒星のUV光で励起され赤く光る）。
占星術との親和性：**赤い星雲 = 宇宙の情熱・感情のエネルギー**

実装アイデア:
```css
/* ピンク星雲グロウ（右上に1個） */
radial-gradient(ellipse 30% 18% at 72% 18%,
  rgba(180, 60, 160, 0.14) 0%, transparent 100%),
/* 小さなピンク星雲（左下に1個） */
radial-gradient(ellipse 20% 12% at 22% 78%,
  rgba(160, 50, 140, 0.09) 0%, transparent 100%),
```

### 天の川帯（暖色の対角線帯）

銀河中心方向に向かう、淡い琥珀色の星の密集。

```css
/* 天の川コア（対角線上） */
radial-gradient(ellipse 50% 70% at 42% 58%,
  rgba(120, 85, 40, 0.12) 0%,
  rgba(70, 45, 15, 0.06) 55%,
  transparent 100%),
```

## 優先度

- ピンク星雲追加: **HIGH** — 1行追加、視覚的インパクト大
- 天の川暖色帯: **MEDIUM** — 繊細な追加、depth感が増す
- ベース色調整（青灰方向へ）: **LOW** — 現在のネイビーで十分
