## 4枚の画像観察

### 画像③-a: 爆発エフェクト（近距離・混沌）
```
黒背景 + 中心の強烈な白発光
  │
  ├── 大型幾何学星（紫〜青白、6〜8点）
  ├── 球状の輝く弾（ピンク・赤・白）
  ├── 紙吹雪状の小片（白・矩形）が全方向に飛散
  └── 中心から放射状に飛び出す粒子群
```
- **中心に強烈なbloom** — 白く溶けるような光源
- **additive blending全開** — 重なった部分が白く輝く
- **大小・形状の混在** = 大型装飾星 + 中型球体 + 小型パーティクル

### 画像③-b: 曲線弾幕（美しいドット軌跡）
```
深ネイビー〜黒背景 + 竹林シルエット

  緑    黄    ピンク〜紫
  ●    ●       ●
  ●  ●  ●   ●  ●
●       ●       ●     ← 6点星形ドットが間隔を空けて連なる
  ●  ●  ●   ●  ●
    ●        ●

    → なめらかな曲線・S字・円弧を描く
```
- **ドットが間隔を保って軌跡を形成** = 星が「線」になっている
- 色: 緑→黄→ピンク→紫→青白（グラデーション遷移）
- 魔理沙のシルエットが画面中央に極小で写る

### 画像③-c: 銀河状スパイラル（最も美しい1枚）
```
画面の7割を巨大スパイラルが占める:

      白 → 水色 → 緑 → 黄緑 → ピンク
  ─────────────────────────────────→
  小さなドットが等間隔に並ぶ螺旋腕が
  5〜8本、中心から外へ広がっている

           ↓ まるで銀河の腕
```
- **対数螺旋（ゴールデンスパイラル）** に見える
- 背景: 深ネイビー + 竹林シルエット（ここでも fortuneP と同じ夜空）
- 魔理沙が左下に立っており、圧倒的なスケール差

### 画像③-d: 複合弾幕（全要素混在）
```
  大型星（紫〜ピンク）   スパイラルドット（水色〜金）
      ↘                    ↗
          魔理沙（中央）
      ↗                    ↘
  小型発光点（散在）     花形のドット列（金・小型）
```
- 大 / 中 / 小の3スケールが同時存在
- 右下の金色花形ドット列が特に美しい

## 弾幕の視覚文法（設計パターン抽出）

### パターン1: 大型幾何学星
```css
/* 6点または8点のアウトライン星形 + 内部glow */
形状: clip-path polygon または SVG
サイズ: 60〜150px
色: 単色ソリッド + 外側にbloom glow
配置: 3〜8個、画面に大きく存在感を持たせる
```

### パターン2: 発光ドット軌跡
```
ドットの並びが曲線を作る:
  ● → ● → ● → ●（間隔均等）

sin/cosで軌跡を計算し、
一定間隔で点を配置すると「光の線」になる
```
数式: `x = r * cos(t)`, `y = r * sin(t)` (円弧)
または対数螺旋: `r = a * e^(b*t)`

### パターン3: 中心爆発
```
中心点から放射状にパーティクルが飛ぶ:
  velocity = direction * random_speed
  大きさ = 生まれた時は大 → 死ぬ前は小
  opacity = 1.0 → 0 (age-based)
```

### パターン4: 色遷移グラデーション
各弾幕の弾が位相に応じて色が変わる:
```
位置角度0°   = 白
位置角度60°  = 黄緑
位置角度120° = 緑
位置角度180° = 水色
位置角度240° = ピンク
位置角度300° = 紫
```
→ レインボースペクトルの連続遷移

## 東方弾幕 × 占星術の接続

この画像群が示す「弾幕」は実は**占星術の星座**と数学的に同じ構造:

| 弾幕 | 占星術 |
|---|---|
| 螺旋する光の粒子群 | 星座を結ぶ星の軌道 |
| 中心から放射する弾 | 黄道12宮の中心（太陽） |
| 色の遷移（レインボー） | 12星座のエレメント（火・地・風・水） |
| 大型★ + 小型ドット | 主要星 + 背景の小星 |

fortuneP のホロスコープ表示（太陽・月・ASC）を、
弾幕的な視覚言語で表現することができる。
