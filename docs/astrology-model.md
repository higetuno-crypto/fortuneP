# fortuneP 占星術モデル定義

## 1. このドキュメントの役割
このファイルは、fortuneP がサービス内で扱う**占星術の基礎概念・見せ方・翻訳方針**を定義するための文書である。

目的は以下。
- 占星術コンテンツの軸を揃える
- UI上の見せ方と占星術の意味を接続する
- AIや人間が文章を書くときのブレを防ぐ
- 初心者向けの言い換えと、占星術本来の意味を両立する

この文書は `docs/product-foundation.md` を前提とし、fortuneP における**占星術の辞書**として扱う。

---

## 2. 前提姿勢
fortuneP は、**西洋占星術の基本的な枠組み**をベースにする。

ただし、サービスとしては以下のバランスを取る。
- 学術論文のような厳密性より、占星術として筋が通っていることを重視する
- 初心者が読める言葉に翻訳する
- ふわっとした雰囲気だけの占いにはしない
- 専門家向けの難解さにも寄りすぎない

つまり、

**「占星術として意味が通ること」**
と
**「一般ユーザーが楽しく理解できること」**
を両立させる。

---

## 3. fortuneP における最重要3要素
MVPで中核にするのは以下の3つ。

1. 太陽星座
2. 月星座
3. アセンダント

この3つで、ユーザーにとってわかりやすい立体感を作る。

### サービス内の基本翻訳
- 太陽星座 = 表の核 / 人生で育てる光
- 月星座 = 心の奥 / 安心したいときの反応
- アセンダント = 外側の入口 / 人から見える雰囲気

この翻訳は便利だが、簡略化でもある。
よってコンテンツ設計では、元の意味を壊さないよう注意する。

---

## 4. 太陽星座の定義
### 占星術上の意味
太陽は、西洋占星術において以下を象徴する。
- 自我
- 意志
- 生き方の核
- 人生で育てていく中心性
- 主体性

### fortuneP での見せ方
サービス内では、太陽星座を
**「表の核」「人生で育てる光」「自分らしさの中心」**
として扱う。

### UI / コンテンツでの翻訳例
- 人前で見せやすい性質
- 目指しやすい自分の方向
- 自分らしさの中心にある光

### 注意点
- 太陽星座だけを「表面だけ」として軽く扱わない
- 太陽は単なる外向きペルソナではなく、人生の中心テーマでもある
- 「表の自分」と言うときも、浅い意味にしすぎない

---

## 5. 月星座の定義
### 占星術上の意味
月は、西洋占星術において以下を象徴する。
- 感情
- 本能的反応
- 安心の仕方
- 素の状態
- 心の居場所
- 無意識的な反応

### fortuneP での見せ方
サービス内では、月星座を
**「心の奥」「本音の反応」「安心したいときに出る自分」**
として扱う。

### UI / コンテンツでの翻訳例
- 疲れたときに戻る心の場所
- ひとりのときに出やすい反応
- 守りたい感情の形

### 注意点
- 月星座を単なる“裏の顔”と決めつけすぎない
- 月はネガティブな裏面ではなく、安心や感情の土台でもある
- 「隠れた本性」だけに寄せない

---

## 6. アセンダントの定義
### 占星術上の意味
アセンダントは、西洋占星術において以下を象徴する。
- 第一印象
- 外側の雰囲気
- 世界との接点
- 外界への反応の入り口
- 見られ方

### fortuneP での見せ方
サービス内では、アセンダントを
**「人から見えるあなたの入口」「最初に伝わる雰囲気」「外側のキャラクター」**
として扱う。

### UI / コンテンツでの翻訳例
- 初対面で伝わりやすい印象
- 外の世界に触れるときの顔
- 人から受け取られやすい空気

### 注意点
- アセンダントを“偽りの自分”と扱わない
- あくまで外界との接点であり、嘘の仮面ではない
- 出生時間が必要であることを明確に説明する

---

## 7. 3要素の組み合わせ方
fortuneP の大きな魅力は、3つを単独で見るだけでなく、**重ねて読むこと**にある。

### 基本構造
- 太陽星座: 自分の中心にある光
- 月星座: 心の奥の安心と反応
- アセンダント: 外側に伝わる印象

### ユーザーへの体験翻訳
- 外から見るとこう見えやすい
- 心の中ではこう感じやすい
- 人生の中心にはこういうテーマがある

### 統合結果で扱いたいこと
- 見た目と内面のギャップ
- 表に出やすい魅力
- 心が落ち着く条件
- 周囲に誤解されやすいポイント
- 本来の力が出やすい状態

## 8. MVP後に扱う追加要素

### 水星

- 話し方
- 情報処理のスタイル

### 金星
- 好み
- 魅力の出し方
- 愛情表現
- 心地よさの感覚

### 火星
- 行動力
- 欲求の出し方
- 怒り方
- 前に進むエネルギー

### ハウス
- 星の力が表れやすい人生領域

### アスペクト
- 星同士の関係性
- 力がスムーズか、緊張感があるか

ただし、追加するときも初心者に伝わる翻訳が必要。

## 9. サイン解釈の基本姿勢
12サイン（牡羊座〜魚座）を扱うときは、テンプレ的な性格決めつけを避ける。

### 避けること
- 牡羊座は短気
- 乙女座は細かい
- 蠍座は重い
のような単純化しすぎた決め打ち

### 目指すこと
- サインのエレメントやモード感も踏まえる
- 長所と影の両方を見せる
- ひとことで決めつけず、動きや反応として表現する

### 例
悪い例:
- 蟹座だからメンヘラっぽい

良い方向:
- 蟹座の性質が強いと、安心できる居場所や感情のつながりを強く求めやすい

## 10. 診断文作成ルール
### 必ず入れたい視点
- その星が象徴するテーマ
- そのサインが与える色合い
- ユーザーに伝わる日常的な表れ方
- やさしい余韻

### 基本テンプレート
1. その要素の役割を伝える
2. そのサインの色を説明する
3. 日常でどう出やすいかを描く
4. 魅力と注意点を両方書く
5. 余韻のある締めにする

### 必要なバランス
- 褒めすぎない
- 下げすぎない
- 決めつけすぎない
- ぼやかしすぎない

---

## 11. 不確実性の扱い
占星術では、入力情報が足りないと解像度が下がる場合がある。
fortuneP では、それを誠実に扱う。

### ルール
- 出生時間がない場合は、アセンダントを原則出さないか、参考扱いにする
- 説明で「正確な出生時間があると、より深く読めます」と伝える
- 無理に断定しない

### 避けること
- 不足情報があるのに断定する
- 精度の低い情報を確定情報のように見せる

---

## 12. 視覚表現との接続
占星術モデルは、文章だけでなく視覚表現にもつなげる。

### 例
- 太陽星座: 中心の光、中心円、主役感
- 月星座: やわらかい光、内側の円、静かな波
- アセンダント: 外縁、入口、外へ開く動き

ホロスコープやアイコンでも、意味と見た目がつながるようにする。

---

## 13. 参考姿勢
fortuneP は、以下のような西洋占星術の一般的な文脈を踏まえて設計する。

- 太陽 = 自我・中心性
- 月 = 感情・安心・本能
- アセンダント = 第一印象・外界との接点
- 惑星 = 機能
- サイン = その機能の表れ方
- ハウス = 表れやすい領域
- アスペクト = 関係性

この骨組みを崩さず、初心者向けに翻訳することが重要。

---

## 14. AI利用時の共通指示
AIに占星術解釈や文章作成を依頼するときは、以下を前提として伝える。

- 西洋占星術の基本文脈に沿う
- 太陽・月・アセンダントを中核にする
- 初心者向けにわかりやすく翻訳する
- 断定しすぎない
- ステレオタイプ化しすぎない
- 神秘感はあっても、意味を失わない

である。
