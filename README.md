# fortuneP

fortuneP は、**西洋占星術をベースに、自分の表の顔と内面の顔を楽しく深く知るためのモバイル中心の占いサイト**です。

神秘的でかわいい世界観と、スマホで迷わず使える体験を両立しながら、
**太陽星座・月星座・アセンダント**を軸に「表の自分」「心の奥」「人から見える雰囲気」を読めるプロダクトを目指しています。

---

## このプロジェクトが目指すもの

fortuneP は、単なる軽い診断サイトではなく、次の要素を同時に満たすことを目標にしています。

- 神秘的で惹かれる世界観
- かわいくてスクショしたくなる見た目
- 初心者でもわかりやすいUI
- 西洋占星術として筋の通った説明
- 何度も見返したくなる結果体験

一言でいうと、

> **「神秘的でかわいい世界観の中で、西洋占星術を使って“表の自分”と“心の奥の自分”を知る、スマホ向け占星術サイト」**

です。

---

## 現在のMVP方針

最初の公開版では、機能を広げすぎず、以下の体験に集中します。

- 生年月日を入力する
- 太陽星座を知る
- 月星座を知る
- 可能ならアセンダントを知る
- 「表の自分 / 心の奥 / 人から見える自分」を読む
- 結果を気持ちよく見て、シェアしたくなる

後から広げる候補として、以下を想定しています。

- 恋愛傾向診断
- 仕事 / 才能診断
- 相性診断
- 今日の運勢
- 詳細ホロスコープ
- 有料の深掘り鑑定

## fortuneP の擬似チーム構成

このプロジェクトは、役割ごとのエージェントを使って、**一人開発でもチーム開発のように進める**前提で整理しています。

現在の主要エージェントは以下です。

- Product Planner
- UX/UI Designer
- Astrology Researcher
- Content Architect
- Technical Architect
- Frontend Engineer
- Breaker / QA
- Growth Marketer
- Monetization Strategist
- Analytics / Experimenter

詳しくは `docs/agents/README.md` を参照してください。

---

## 開発の進め方

基本はこの順番で進めます。

1. 方針を `docs/` に固定する
2. 役割ごとのエージェントで論点を分ける
3. MVPに必要なものだけを実装する
4. 触ってもらい、反応を見て改善する
5. その後に機能を広げる

### 議論するときの共通ルール
- `docs/product-foundation.md` を最上位ルールにする
- 占星術解釈は `docs/astrology-model.md` に従う
- 言葉づかいは `docs/brand-voice.md` に従う
- MVP判断は `docs/mvp-scope.md` を優先する
