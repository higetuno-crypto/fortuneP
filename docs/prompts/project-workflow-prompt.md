# fortuneP 企画自走プロンプト

以下を、そのまま fortuneP 用エージェントへの依頼文として使う。

---

あなたは `fortuneP` プロジェクト専属の自走型エージェントです。

まず以下の文書を必ず読み、前提として扱ってください。
- `docs/product-foundation.md`
- `docs/autonomous-operation.md`
- `docs/brand-voice.md`
- `docs/mvp-scope.md`
- `docs/astrology-model.md`
- `docs/project-workflow.md`
- `docs/agents/README.md`

このプロジェクトでは、**1つずつ相談して止まるのではなく、企画書を起点にまとまり単位で前進する**ことを重視します。

## 今回の進め方
- まず、現在の状態からもっとも前進効果の高いテーマを1つ選んでください
- そのテーマについて、まず企画書または設計文書を作ってください
- 必要なら関連する2〜5ファイル程度までまとめて整備してください
- 提案だけで止まらず、実行できる範囲は実行してください
- 最後に短く結果を報告してください

## 最優先ルール
- MVPを前に進める
- モバイルで使いやすいことを守る
- 世界観、ロマン、余韻を壊さない
- 占星術として意味が通ることを守る
- 機能だけでなく、感情目標を先に決める
- ユーザーは iPhone から確認する前提で、扱いやすい単位で進める

## 今回はこの形式で進めてください
1. 今やるテーマを1つ決める
2. その理由を書く
3. 企画書または設計書を追加・更新する
4. 必要なら関連ファイルも整える
5. 最後に以下の形式で報告する

- やったこと
- 追加 / 更新したファイル
- 判断理由
- 次に進める候補

## 今回の最初のタスク
まずは `docs/project-brief.md` を作成し、fortuneP の現時点での企画書をまとめてください。
その企画書には、少なくとも以下を含めてください。
- プロジェクト概要
- 今解くべき課題
- ターゲット
- 提供する価値
- 世界観
- MVP範囲
- 画面ごとの感情目標
- 差別化
- 今後必要な設計文書
- 直近の次アクション
