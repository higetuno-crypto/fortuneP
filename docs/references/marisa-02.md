## キャラクターデザイン確定要素

### 帽子（最重要モチーフ）
```
       ╭──────────────────────────╮
       │   大きな白いリボン / 蝶結び   │  ← 最大の特徴
       ╰──────────────────────────╯
  ╭─────────────────────────────────────╮
  │           黒い広つばハット             │  ← 広い・存在感が大きい
  ╰─────────────────────────────────────╯
        │ 白いフリルの帽子バンド │
```
- **帽子の色**: 深いネイビーブラック（純黒ではなく `#1a1a2e` 相当）
- **リボン**: 白・大きな蝶結び。帽子の存在感と同等かそれ以上
- **フリル**: リボン下・帽子バンド部分にフリル装飾
- **帽子の先**: やや曲がっている（先端が少し傾く）

### 髪
- **色**: 明るいゴールド〜小麦色（`#e8c860` 〜 `#d4a830` 相当）
- **スタイル**: 長い → **三つ編みおさげ**に結ばれている
- **量感**: 多く、ふわっと広がる

### 瞳
- **色**: 黄緑色（`#8fba20` 相当）。金色に近い緑

### 服装（確定）
| パーツ | 詳細 |
|---|---|
| インナー | 白いブラウス・ふわっとした袖（フリル気味） |
| アウター | 黒いエプロンドレス（前面に**金の丸いボタン**が縦に並ぶ） |
| 胸元 | **緑のリボン**（アクセント色） |
| スカート | 黒・フレア。白いフリル裾 |
| 全体 | 白 × 黒 × 金 × 緑 の4色構成 |

### 箒
- 茶色い柄 + **金色の先端**（穂の根元が金）
- 箒に「またがって」飛ぶポーズ

## 参考画像②-b: 夜空飛翔シーン（minusT 3DCG）

### 背景が完全に fortuneP の目標と一致している

```
[ 深ネイビー〜黒グラデーション ]

        ·  ·   ·    ·   · ·    ·     ← 小さな白い星点
   ·  ·   ·  ·        ·     ·  ·  ·
·    ·      ·   ·   ·    ·        ·

          魔理沙（箒に乗って飛翔）
             後ろ姿・斜めアングル

████████████████████████████████████  ← 草・木のシルエット（暗い）
```

| 要素 | 詳細 |
|---|---|
| 背景色 | 上部: `#060c1e` / 中央: `#0a1428` / 下部: `#14202a` |
| 星 | 小さな白い点。密度は中程度。均一に散らばっている |
| 地平線 | 暗い草・木のシルエット（黒〜暗緑） |
| グロウ | なし。静かでシンプルな夜空 |
| 魔理沙の位置 | 画面中央〜右上。箒のシルエットが明確 |

**この構図こそが fortuneP の「流れ星アニメーション」で目指すべきイメージ**:
- 夜空を斜めに横切る魔理沙のシルエット
- 周囲に点在する星
- 速度感のある構図（傾いた体・広がるスカート）
