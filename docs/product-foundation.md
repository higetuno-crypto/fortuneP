## サービスの核

fortuneP は、**西洋占星術をベースに、自分の表の顔と内面の顔を楽しく深く知れる、モバイル中心の占いサイト**。

ユーザーに与えたい体験:
> **「見た目がかわいくて惹かれたのに、読んでみたら想像以上にちゃんとしていて、自分のことをもっと知りたくなる」**

さらに fortuneP は**雰囲気そのものが価値**。
> **「夜にひとりで読みたくなり、静かな星空や一瞬の箒星のようなロマンを感じながら、自分の心に触れる体験」**

## 世界観の定義

### コアモチーフ（使ってよいキーワード）
星 / 夜空 / 月 / 惑星 / 魔術 / 秘密 / 運命 / きらめき / 内面 / 鏡写しの自分 / 箒星 / 一瞬の輝き

### 雰囲気
神秘的 / 幻想的 / 少し魔女的 / 少しロマンチック / 静か / 余白がある / 親しみやすい（閉じすぎない）

### 世界観のNG
- 騒がしい演出・安っぽいスピリチュアル表現
- 子どもっぽすぎるかわいさ
- 特定作品の二次創作にしない（オリジナルのサービスとして成立させる）
- 派手で騒がしい魔法世界（静かで深いきらめきを優先）

---

## ターゲットユーザー

**主なターゲット**: 女性 / 女子高生〜20代前半 / サブカル趣味 / コミケ参加者・創作好き / Vtuber好き / 星・月・夜空・魔法モチーフが好きな人

### 価値観・嗜好（設計時に参照）
- かわいいものが好きだが、使いにくいUIは嫌う
- 軽い遊びとして占いを楽しむが、薄すぎる内容には冷める
- SNSでシェアしたくなる見た目に反応しやすい
- 心の奥や恋の機微を雑に扱われたくない

### UX上の前提
- モバイル（iPhone）で使う前提を最優先
- 難しい言葉が並ぶと離脱しやすい
- 「ちゃんとしている感じ」は欲しい

---

## 開発環境の前提（iPhone操作前提）

ユーザーがiPhoneから進行管理する前提で、AI提案時は以下を守る:

- 手順は短く区切る
- そのまま使えるテキストを優先する
- 「まず何を押すか」「次に何をするか」が一目で分かる形にする
- 長文の複雑な操作手順を避ける
- コピペしやすい形で出力する

## 占星術の基礎概念

| 概念 | MVPでの扱い | fortuneP内の翻訳 |
|---|---|---|
| 太陽星座 | **必須** | 外向きの性質・人生で育てる核 → 「表の核」 |
| 月星座 | **必須** | 感情・本音・安心の仕方 → 「心の奥」 |
| アセンダント | **必須（条件付き）** | 第一印象・見られ方 → 「人から見える入口」 |
| 水星・金星・火星 | MVP後に段階導入 | — |
| ハウス・アスペクト | MVP後に段階導入 | — |

**わかりやすさのために意味を壊しすぎないこと。**

## コンテンツ文章の原則

### 方向性
やさしい / 神秘的 / 少し詩的 / 意味はわかる / 断定しすぎない / 余韻がある

### 避けること
- ぼんやりした言葉だけで終わる表現
- 強すぎる断定（「必ず〜します」「あなたはこういう人です」）
- 難しすぎる専門用語の連打
- テンプレっぽさが強い文章
- 安っぽく恋や感情を煽る表現

### 理想の読後感
「なんか当たってるかも」「かわいいのにちゃんとしてる」「もっと読みたい」「少し胸が動いた」

---

## 衝突時の優先順位

1. 占星術として意味が通っているか
2. モバイルで使いやすいか
3. 世界観・ロマン・余韻を深められるか
4. 演出は後から足せるか

→ **意味と使いやすさを壊してまで雰囲気を優先しない。そのうえで、制約の中で世界観を最大化する。**

> fortuneP は、**「神秘的でかわいい世界観の中で、西洋占星術を使って"表の自分"と"心の奥の自分"を知り、静かな星空のようなロマンと余韻を味わえる、スマホ向け占星術サイト」** である。

この定義からズレる提案は、基本的に採用しない。
