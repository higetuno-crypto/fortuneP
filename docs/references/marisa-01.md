## 「幻想的でキラキラした存在感」の正体

この画像から読み取れる「キラキラ感」の構成要素:

### 1. 白い幾何学的な星（最重要）
```
  ★  ← 多角形の鋭いシルエット
  ☆  ← 白一色、透明感のある存在
```
- 小〜大のサイズ差がある
- 光源のような輝きではなく**形として存在する星**
- 数個〜十数個、画面に散らばっている

### 2. ボケた光の点（輝点）
- 画面下部に複数の白い円形ボケ
- フォーカスが外れたような柔らかい輝き
- 大小混在（3px〜15px相当）
- 既存 fortuneP の bokeh に近い

### 3. 水彩の透明な重なり
- 色が混じり合い、境界が曖昧
- 透明感 = 「溶け込む」ような存在感
- 青紫のインク滲みが「魔法的な空間」を演出

### 4. 流れる金髪
- 渦巻くように広がる
- 静止ではなく「動き」「エネルギー」の表現
- 魔力の軌跡のような螺旋

## fortuneP への示唆

### カラーパレットの一致
この画像のパレットは fortuneP と**ほぼ一致している**:

| 魔理沙参考画像 | fortuneP テーマカラー |
|---|---|
| 深ネイビー・インディゴ | `fp-navy: #0a0e1a`, 背景 `#08102a` |
| 白い幾何学的な星 | 現在の白い star-spike（方向性○） |
| 金髪 | `fp-gold: #c9a84c` |
| 青紫の水彩 | `fp-purple: #2d1b69`, `fp-glow: #8ba7d9` |
| 白いボケ玉 | 現在の `.bokeh`（ただし金色 → 白も検討） |

### 「幾何学的な白い星」を足す
現在の fortuneP は点状の星だけ。
この画像の **シャープな白い星形（★）** を数個散らすと一気に魔理沙感が出る:

```css
/* SVG or CSS clip-path で星形を作る */
.deco-star {
  position: absolute;
  width: 16px; height: 16px;
  background: white;
  clip-path: polygon(
    50% 0%, 61% 35%, 98% 35%, 68% 57%,
    79% 91%, 50% 70%, 21% 91%, 32% 57%,
    2% 35%, 39% 35%
  );
  opacity: 0.6;
  filter: drop-shadow(0 0 4px rgba(255,255,255,0.8));
}
```

### 浮遊感・重力のなさ
逆さまの構図が示すように、「宇宙に漂う」体験は
**上下の概念を消すこと**で表現できる。
星のアニメーションに、わずかな Y 軸の浮遊運動を加えることで表現可能。
