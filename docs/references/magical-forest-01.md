# 参考画像: 魔法の森の小屋

## 画像の概要

深夜の森の中に佇む石造りの小屋。古木の根元に建てられ、
光るキノコ・鈴のような花・木に刻まれたルーン文字・煙突から漂うシアンの煙が
穏やかに共存している。

## ユーザーのコメント

> 派手さの裏には、影ながらの努力や、穏やかな雰囲気の時間がある。
> ユーザーが没入できるような、穏やかな魔法の時間

## 視覚的要素の分解

### 光の種類（2層構造）

| 種類 | 色温度 | 動き | 役割 |
|---|---|---|---|
| 窓の明かり | 暖色 `#ffd080`〜`#ff9020` | 静止（揺らぎ微小） | 生活感・安心感 |
| キノコの発光 | 冷色 `#a0e8ff`〜`#80ffee` | ゆっくり明滅 | 魔法感・異世界 |
| ホタル/浮遊光 | 暖色 `#ffc040`〜`#ffdd80` | ゆっくり上昇・漂う | 命の息吹・有機感 |
| ルーン文字 | シアン `#40ffcc`〜`#00ddff` | 流れるように発光 | 知性・呪文 |
| 星空 | 白・青白 `#ffffff`〜`#c8dcff` | 瞬き | 宇宙・距離感 |

### 奥行き構造

```
[前景] 白い鈴草・草 — やわらかいグロウ
[中景] 石造りの小屋・キノコ — 主役の温かい光
[後景] 古木・ルーン — 冷たいシアンの輝き
[最奥] 星空・天の川 — 深い紺
```

→ **近いほど暖色 / 遠いほど冷色** という自然な奥行きの法則

### fortunePとの対比

現在のfotunePは「冷たい宇宙」寄り（深ネイビー＋シアン＋白の星）。
この画像が示すのは：**同じ夜空の下に、温かい生命の光がある**という二重性。

```
現在:  深宇宙 ←—————————— 全体が遠い/冷たい
理想:  深宇宙 ← 星空 ← 魔法陣 ← ユーザーの手元（暖かい）
```

占星術という行為は、遠い星を「自分のこと」として読む。
冷たい宇宙と、温かい個人の物語をつなぐ体験。

## fortfunePへの応用アイデア

### 1. ホタル浮遊パーティクル（実装難度: 低）

```css
/* 小さな琥珀色の光球がゆっくり上昇 */
.firefly {
  width: 3px; height: 3px;
  background: #ffc040;
  border-radius: 50%;
  box-shadow: 0 0 4px 2px rgba(255,180,40,0.8),
              0 0 10px 4px rgba(255,150,20,0.3);
  animation: ff-float var(--dur) ease-in-out infinite;
  animation-delay: var(--del);
}
@keyframes ff-float {
  0%   { transform: translateY(0) translateX(0);     opacity: 0; }
  20%  { opacity: 0.9; }
  50%  { transform: translateY(-40px) translateX(8px); opacity: 0.6; }
  80%  { opacity: 0.4; }
  100% { transform: translateY(-90px) translateX(-5px); opacity: 0; }
}
```

→ 現在の「冷たい星空」に **温かい命の動き** を加える

### 2. 魔法陣ルーン（実装難度: 中）

magic-circleの外周に、発光するルーン文字列が流れるように回転。
`stroke-dashoffset` アニメーションでSVGテキストパスを描画していく。

### 3. 背景に「窓の光」的な暖色グロウ（実装難度: 低）

```css
/* magic-circleの後ろに、奥から射してくる温かい光 */
.mc-warm-glow {
  position: absolute;
  width: 300px; height: 300px;
  border-radius: 50%;
  background: radial-gradient(circle,
    rgba(201,130,40,0.12) 0%,
    rgba(160,90,20,0.06) 40%,
    transparent 70%);
  filter: blur(20px);
  animation: warm-pulse 6s ease-in-out infinite;
}
```

→ 金色の魔法陣が「内側から光っている」ような表現に

## 設計哲学としての示唆

この画像が言っているのは：

> **「美しいものには、見えない暖かさがある」**

- 派手な弾幕の背後には、静かに星を学ぶ魔理沙がいる
- キラキラした星空の下には、温かい灯りの部屋がある
- 占いの結果の派手さの裏には、星と向き合う静かな時間がある

fortfunePに今足りないのは、**ユーザーが「ここに居たい」と思える温かさ**かもしれない。

## 優先度

- ホタルパーティクル: **HIGH** — CSS数行で実装可能、効果大
- 暖色グロウ補強: **MEDIUM** — magic-circleの奥行き感が増す
- ルーン文字: **LOW** — SVGテキストパス必要、工数大
