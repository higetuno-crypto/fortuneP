## スクリーンショット観察

### 背景色
- **深ネイビーブルー** — 純黒ではない。`#060c1e`〜`#08102a` 相当
- 上部はやや暗め、下部に向かってわずかに明るい
- 宇宙の「深み」ではなく「夜空を見上げている」感覚に近い

### 星の構成（3層構造）

| 層 | 特徴 |
|---|---|
| **遠景の星群（最多）** | 0.5〜1px の白い点が画面全体に均一に散らばる。天の川的なテクスチャ |
| **中景の星** | 1〜2px。少し明るく、点として認識できる |
| **フォーカル輝き星（1つ）** | 画面中央やや上。4方向に伸びる長い光条（十字スパイク）。白く輝く核＋青白いglow |

### 十字スパイク星（核心）
- 4方向（上下左右）に細い光の筋が伸びる
- 筋の長さ: 約50〜70px相当
- 筋の質感: 中心が明るく、端に向かって透明に
- 核: 白く強く輝く（box-shadow多層）
- 周囲: 青白のhalo

### 下部の演出
- 底辺に向かって **青い大気光** （nebula glow）
- 画面端より内側で滲んでいる — まるで惑星の大気のような効果

### 色
- 星: 白 (#ffffff) と青白 (#d0e4ff, #c8dcff) が混在
- 背景: ネイビー (#060c1e〜#08102a)
- 大気光: 青 (rgba(30, 60, 140, 0.3))

## 「煌めき・瞬き」の正体

ユーザーが求めている「煌めき的な、瞬き的な物」は:

1. **密度** — 無数の小さな点が全面に広がること
2. **階層感** — 微小な点から輝く星まで、サイズ差があること
3. **フォーカル・ポイント** — 1〜2個の「特別に輝く星」が目を引くこと
4. **色の揺れ** — 純白だけでなく青白が混じること
5. **背景の色** — 純黒より深ネイビーの方が星が「浮いて見える」

純黒背景は星との境界がシャープすぎる。
**ネイビーブルーにすることで、星が「空の中に浮かんでいる」感覚になる。**

## fortuneP への実装内容（実施済み）

このスクリーンショットを参考に、全4ページに以下を適用した:

| 変更 | 詳細 |
|---|---|
| 背景色 | 深紫 → 深ネイビーブルー (`#060c1e`〜`#08102a`) |

| 星の種類 | `star-micro`(微小密集) / `star-small`(中) / `star-bright`(輝き) / `star-spike`(十字) |

| スパイク星 | 十字フレアCSSをすべてのページに追加（1〜2個/ページ） |
