## 参考サイト

### ① Solar Journey
**URL:** https://solar-journey.webflow.io/#planet-end

#### 評価
| 項目 | 内容 |
|---|---|
| ★ 高評価 | サイトを開いた際のロード画面のUI / ハンバーガーメニューのUI |

#### 観察メモ（スクリーンショットより）
- **ロード画面：** 純黒背景 + 下部に暖色glow（太陽が画面下に隠れているイメージ）。中央に細い円、内部に薄いジオメトリック線（十字+斜め6方向）。進捗%を大きく中央表示。外周を動く白い点がトラッカーとして機能。
- **メニュー：** 点線の同心円で太陽系を表現。惑星はサイズ比に近い白い円のみ。ラベルは「Sun」のみ。非常に設計図的・図鑑的な美しさ。
- **タイトル：** 純黒背景に薄いジオメトリック線（円+三角形）を背後に置き、その前に極限まで大きな細ウェイトサンセリフ。"SOLAR" / "JOURNEY" で行分け、左端をズラして動きを出す。
- **メニューボタン：** 右上に「細い円形ボーダー + ≡ 2本線」。Solar Journey らしい品のあるUI。
- **カラー：** 完全モノクロ（黒+白のみ）。ローダー下部の暖色グロウだけが唯一のアクセント。

#### fortuneP への示唆
- **ロード画面**：現状の魔法陣ローダーに「進捗%表示」「外周を動くトラッカー」を追加するとよりセンスが出る。
- **タイトル**：魔法陣をタイトルの「背後」に移動させ、タイトル文字をもっと大きく・細く表示する構成が参考になる（現状は魔法陣が独立したセクション）。
- **惑星軌道の表現**：result ページの3天体バッジを「点線の同心円 + 軌道上に天体配置」で表現すると世界観が一段上がる。
- **詳細分析：** `docs/references/solar-journey.md` を参照。

### ② 100,000 Stars (Chrome Experiments)
**URL:** https://stars.chromeexperiments.com/

#### 評価
| 項目 | 内容 |
|---|---|
| ★ 高評価 | 星の立体感、没入感 |
| ✗ 低評価 | iPhone16でも少し重たい / スライドバー操作は楽しいが、星の輝きが綺麗な箇所が少ない |
| → フィードバック | 星空の中を漂う体験自体はかなり良い |

#### 観察メモ（スクリーンショットより）
- **星の多層glow構造:** 白核 → 青白inner glow → 広いouter glow → 暖色halo（近い星ほど全層が大きい）
- **太陽:** 中央に最大・最明。純白核 + 暖色オレンジの広いhalo。隣接星と重なるほど巨大。
- **距離感の仕組み:** 近い星（大きなglow）→ 遠い星（2pxの点）という連続的なグラデーション。**これが「宇宙を漂う当事者感」の正体。**
- **十字フレア:** 明るい星に光条（lens flare風）が入る。CSSの疑似要素で再現可能。
- **色温度:** 青白（熱い/若い）〜白（中性）〜淡金（太陽型）の3系統が混在。

ユーザーコメント: 「宇宙を漂う当事者感が衝撃だった。光っている星が小さくなっていくのが、星との距離を感じられて良かった」

#### fortuneP への示唆
- **星を4段階（bright/mid/dim/distant）に分類:** サイズとglow強度を変えるだけでCSS上で「奥行き」が生まれる。WebGL不要。
- **色温度の混在:** 現状は全星が白一色。青白・白・淡金（#ffe0a0）を混ぜると星屑の質が一段上がる（金は fortuneP テーマとも一致）。
- **詳細分析 + CSS実装例:** `docs/references/100k-stars.md` を参照。

### ③ Online Star Register (OSR)
**URL:** https://osr.org/oms/ja/

#### 評価
| 項目 | 内容 |
|---|---|
| ★ 高評価 | 星の中を突き進む体験 |
| ✗ 低評価 | 輝きが綺麗な場所が少ない / 太陽が眩しすぎて星が見えない |
| → フィードバック | キラキラ光る星屑の中を漂うのが美しい。箒星が流れると尚良い。東方Projectの弾幕の中を飛び回るような没入感が欲しい |

#### 観察メモ
- **"Start Tour"ボタン** から始まる没入体験。
- 3D/2Dビュー切り替え、局所星・銀河ビューの階層ナビゲーション。
- 「星の中を突き進む」= Z軸方向への前進アニメーション。

#### fortuneP への示唆
- **Z軸前進（星空に飛び込む）** はトップ→入力遷移の演出として使えそう。
- 「弾幕のような星屑」= 密度・速度・輝きが全て揃った状態。
- **箒星（彗星）**: 流れ星が時々横切るだけで没入感が大幅アップ（実装済みだったが魔理沙モチーフと組み合わせたい）。

## 3サイトを横断したデザイン洞察

### 共通する「没入感の条件」

```
没入感 = 星の密度 × 輝きの質 × 動きのなめらかさ × 軽さ
```

| 要素 | fortuneP 現在 | 状態 |
|---|---|---|
| 星の密度 | index:380個、result:110個 | ✅ 実装済み |
| 輝きの質 | 4段階（micro/small/bright/spike）+ 十字フレア | ✅ 実装済み |
| 星の種類 | 白 `#ffffff` + 青白 `#d0e4ff`/`#c8dcff` 混合 | ✅ 実装済み |
| 流れ星 | ブレイジングスター（シアンコメット+軌跡球） | ✅ 実装済み |
| 重さ | CSS animation = 軽量 | ✅ WebGL不要 |
| 背景 | radial-gradient ドーム（プラネタリウム没入感） | ✅ 実装済み |
| 星空ドリフト | 90s scale 1.018 — 漂う感覚 | ✅ 実装済み（index/result） |
| 遷移演出 | なし | ❌ 未着手（LOW優先） |

### fortuneP 独自の方向性

**「東方Projectの弾幕×星占い」の没入感**
- 弾幕 = 密度・輝き・動きの組み合わせ
- 占星術 = 神秘・余韻・静けさ
- → **動と静のコントラスト**: 流れ星が走る一瞬の動 + 星空の静 = 余韻のある没入
- → **「星空の海に浮かぶ」**: プラネタリウムドーム感覚 — linear→radial bg で実現済み
