# fortuneP UI原則

> **役割**: 全UI実装の共通ルール。色・余白・タイポ・コンポーネント・感情設計を定義する。
> **参照元**: `docs/product-foundation.md` §3・§8
> **影響先**: `src/pages/`, `src/components/`, `src/styles/`

## TL;DR

- 深いネイビー/紫/黒ベース、金アクセント、柔らかい発光
- 感情先行：「何を感じてほしいか」を決めてから構造・演出の順で進む
- 骨組み → 質感 → 演出の順で積み上げる（逆・同時は禁止）

---

## 1. 感情目標マップ（実装前に必ず確認）

各画面を実装する前に、この感情目標を参照すること。感情目標のない実装はしない。

| 画面 | 感情目標 | キーワード |
|---|---|---|
| トップページ | 憧れ・神秘・期待 | 「ここを開いてみたい」 |
| 入力ページ | 安心・そっと導かれる感 | 「難しくない、不安じゃない」 |
| ローディング | 儀式感・静けさ | 「星を読んでいる時間」 |
| 結果ページ | 余韻・自分の奥を見た感覚 | 「少し胸が動いた」 |

---

## 2. 配色パレット

| 役割 | 色の方向 | 使用場面 |
|---|---|---|
| ベース背景 | 深いネイビー / 黒 | 全画面の地 |
| アクセント | 金 / パールホワイト | 見出し・強調・ボタン縁 |
| サブカラー | 紫 / ラベンダー | カード背景・境界線 |
| 発光色 | 柔らかい白〜青白 | 星屑エフェクト・ホバー |
| テキスト | 白 / オフホワイト | 本文。暗色背景上で可読性を確保 |

### 禁止
- 明るすぎる蛍光色
- 騒がしいカラフル配色
- 理由のない白背景

---

## 3. テクスチャ・質感

| 要素 | 方針 |
|---|---|
| ガラス感 | 薄い透け感のあるカード（`backdrop-filter: blur` 等） |
| 余白 | 静かな余白。詰め込みすぎない |
| 発光 | 柔らかいグロー。派手なflashは避ける |
| 星屑 | 細かいドット/パーティクル。動きはゆっくり |
| 背景 | 深い暗色グラデーション |

---

## 4. タイポグラフィ

| 項目 | 方針 |
|---|---|
| 本文フォントサイズ | 最小14px（モバイル）|
| 見出し | 少し細身のセリフ or やわらかいサンセリフ |
| 強調 | 金色またはやや明るい白 |
| 行間 | ゆったりめ（`line-height: 1.7〜1.9`） |
| 1行の文字数 | 20〜28字目安（スマホ横幅） |

---

## 5. コンポーネント原則

### カード
- ガラス感のある半透明背景
- 角丸（`border-radius: 12〜16px`）
- 柔らかいシャドウ

### ボタン
- 主要ボタン: 金縁 or 発光感のあるスタイル
- 文言: 短く世界観を乗せる（例: 「星を読む」「結果を見る」「あなたの月を知る」）
- サイズ: タップしやすい高さ（`min-height: 48px`）
- ❌ 「診断スタートはこちら」「次へ進み結果を表示する」は使わない

### 入力フォーム
- 暗色ベース。境界線は薄く
- フォーカス時に柔らかい光のアウトライン
- エラー表示は赤ではなく、やわらかい色合いで

---

## 6. レイアウト・スペーシング

| 項目 | 方針 |
|---|---|
| ブレークポイント | モバイルファースト（375px〜） |
| コンテンツ最大幅 | 640px（中央寄せ） |
| 操作想定 | 片手操作。タップ領域を十分に確保 |
| 情報密度 | 1画面の情報量を下げる。スクロールで読ませる |

---

## 7. アニメーション・演出

| 場面 | 方針 |
|---|---|
| ページ遷移 | フェードイン（0.3〜0.5s） |
| ローディング | 星が読み込まれる儀式感のある演出 |
| 結果開示 | 上から順にフェードイン。急がせない |
| 星屑 | ゆっくり漂う、または静止でも可 |
| ホバー | 柔らかい発光 |

### 禁止
- 速すぎるアニメーション（0.1s以下）
- 大きく飛び跳ねる動き
- ユーザーを急かす点滅
- 構造と演出を同時に設計すること
- 全画面を均等に豪華にしようとすること

---

## 8. 設計の進め方（必須手順）

```
Step 1. 感情目標を決める  ← §1の表を参照。スキップ禁止
Step 2. 低忠実度ワイヤー（骨組み・要素・読む順番）
Step 3. 中忠実度（余白・階層・可読性）
Step 4. 高忠実度（質感・光・装飾・配色）
Step 5. 演出（アニメーション等）
```

---

## 9. 衝突時の優先順位

1. 占星術として意味が通っているか
2. モバイルで使いやすいか
3. 世界観・ロマン・余韻を深められるか
4. 演出は後から足せるか

→ 意味と使いやすさを壊してまで雰囲気を優先しない。
