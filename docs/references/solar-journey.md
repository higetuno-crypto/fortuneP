## スクリーンショット① ローディング画面

```
[ 純黒背景 ]

           ┌─────────────┐
           │  ╲  ╱  ╲  ╱ │  ← ジオメトリック線（薄いグレー）
           │  ╱  ╲  ╱  ╲ │
      ●   │      75%     │  ← 進捗%を中央に大きく表示
           │  ╲  ╱  ╲  ╱ │
           └─────────────┘
             ↑
       外周の円＋追跡する白い点

[ 下部: 太陽の大気が薄く滲む（暖色glow） ]
```

### 観察ポイント

| 要素 | 詳細 |
|---|---|
| 背景 | 純黒 (#000000)。下部にだけ暖色（琥珀〜茶）のグロウ — 太陽が画面下に隠れているイメージ |
| 円 | 細い白線の円（1px以下）。stroke-dasharray で進捗に応じて描画される |
| 内部幾何学 | 十字線＋斜め線（6方向）のハッチパターン。薄いグレー（opacity 15〜20%） |
| 進捗表示 | 中央に大きく「75%」。sans-serif の細ウェイト |
| トラッカー | 円の外周を動く小さな白い点（現在位置マーカー） |
| 全体感 | 非常にミニマル。余白が多く、中央の小さな円に目が引き寄せられる |

### fortuneP への示唆
- **loading.astro の現状**との差分: 現在の魔法陣ローダーに「進捗%表示」「外周を動くトラッカー」を追加するとよりセンスが出る
- 下部のグロウは「太陽（≒星座の象徴）」が画面外にある示唆で巧い。fortuneP では金色グロウで同様の表現可能

## スクリーンショット② メニュー（太陽系ナビ）

```
[ 純黒背景 ]

  🪐→  [ロゴ]              [× 閉じる（円形ボタン）]
  ────────────────────────────────

           ・ （水星）
        ・    （金星）
              ・  ----  （地球）
          ・        ----    （火星）
      ・                         （木星）
    ----(点線の軌道) ─ ─ ─ ─ ─ ─

          Sun ●  ← 中央に大きな輝く円

    ・  （外側の惑星）
  ────────────────────────────────
  [ Julian Fella — Webflow & Webdesign Expert ]
```

### 観察ポイント

| 要素 | 詳細 |
|---|---|
| 軌道 | 点線（dashed）の同心円。均等に配置ではなく、惑星の実際の軌道比率に近い |
| 惑星 | 白い円（サイズが実際の惑星の大きさ比に近い）。グロウなし、pure white |
| 太陽 | 中央の大きな白円。やや大きいだけで特別なエフェクトなし（それでも存在感） |
| ラベル | 「Sun」のみシンプルに表示。他の惑星名はホバーかタップで出る |
| クローズボタン | 右上：円形の細いボーダー内に「×」。ドットが円周上に1つ（装飾） |
| ロゴ | 左上：惑星+ロケットのシルエット。白、シンプルなアイコン |
| 全体感 | 図鑑的・設計図的な美しさ。複雑でなく「必要な要素だけ」 |

### fortuneP への示唆
- **太陽系の同心円ナビ** は fortuneP の「3つの天体（太陽・月・ASC）」のビジュアル化に使える
- result ページのバッジ部分を「軌道図」として表現: 中心=自分、軌道上に☀・☽・↑ を配置
- 点線の同心円は現在の魔法陣に追加しやすい

## スクリーンショット③ ヒーロー画面（タイトル）

```
[ 純黒背景 ]

  [ロゴ]                    [☰ メニュー（円形）]
  ────────────────────────────────

        ╭──────────╮
        │          │
       ◻           ◻   ← 薄いジオメトリック線（円+三角形）
        │          │       背景に馴染む薄いグレー
        ╰──────────╯

  SOLAR
JOURNEY

  A STELLAR WEB DESIGN ODYSSEY




          Explore
            ⬤   ← 下部スクロール誘導
```

### 観察ポイント

| 要素 | 詳細 |
|---|---|
| 背景 | 純黒。ジオメトリック（円+三角形の構造線）が薄いグレーで重なる |
| タイトル文字 | **極細の大型サンセリフ**。"SOLAR" と "JOURNEY" で行分け、異なる左端位置でズレを表現 |
| タイトルサイズ | 画面幅いっぱい（"JOURNEY" は端まで届く）。boldよりもlightウェイトで繊細 |
| サブタイトル | 小さくすべて大文字スペーシング：`A STELLAR WEB DESIGN ODYSSEY` |
| メニューボタン | 右上：細い円形ボーダー内に「≡」（2本線）。Solar Journey ならではのスタイル |
| 幾何学の役割 | タイトルの後ろに円+三角形。文字との交差で奥行き感 |
| "Explore" | 画面下部に誘導テキスト＋円形ボタン |

### fortuneP への示唆
- **タイトルの大胆なスケール** — "fortuneP" のタイトルをもっと大きく・細く・全画面幅に近づける
- **ジオメトリック線が背景にある** — 現在の魔法陣の位置を「タイトルの背後」に移動させると同じ効果が出る（現在は魔法陣が独立したセクションとして置かれている）
- **メニューボタン** — 現在はナビなし。将来メニューを追加するなら「細い円形ボーダー+アイコン」がこの世界観に合う

## Solar Journey から学ぶ「シンプルの強度」

| Solar Journey の手法 | fortuneP 現状 | 改善アイデア |
|---|---|---|
| 純黒背景（#000000） | 深紫グラデーション（良い対比） | そのまま維持 |
| ジオメトリックをタイトルの背景に置く | 魔法陣が独立セクション | 魔法陣をタイトル背後へ移動 |
| タイトルを極限まで大きく | 2.6rem（適度） | もう一段階大きく・より細く |
| 進捗%をローダー中央に表示 | テキストのみ | %表示＋外周トラッカーを追加 |
| 点線の同心円で惑星軌道を表現 | 実線の魔法陣 | 点線リング + 軌道上に天体を配置 |
| 全色モノクロ（白のみ） | 金・青白・パールの多色 | 金の単色で統一感を強化してもよい |
